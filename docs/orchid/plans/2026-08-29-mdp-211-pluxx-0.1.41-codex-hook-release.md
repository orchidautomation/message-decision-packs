After `@orchid-labs/pluxx@0.1.41` is immutably published and verified, update Message Decision Packs from Pluxx 0.1.40 to 0.1.41, regenerate its host bundles, release MDP 0.1.95, and prove the installed Codex `SessionStart` and `UserPromptSubmit` commands launch without `CODEX_PLUGIN_ROOT`.

## Hard precondition

Do not start implementation until all are true:

1. npm reports exact `@orchid-labs/pluxx@0.1.41` with a registry integrity value;
2. GitHub has immutable tag/release `v0.1.41` bound to a trusted `main` commit containing PLUXX-345;
3. the Pluxx release receipt identifies the exact artifact revision and passed target proof;
4. MDP-211's PLUXX-345 blocker is removed through Linear only after those readbacks.

Merged source alone is insufficient.

## Implementation

1. **Pin the released compiler**
   - Replace every maintained Pluxx 0.1.40 pin in CI, release workflow, hook tests, and documentation with exact 0.1.41.
   - Fetch the registry tarball and compare its integrity with the authenticated Pluxx release evidence before generating artifacts.

2. **Regenerate and inspect bundles**
   - Rebuild Claude Code, Cursor, Codex, and OpenCode from canonical `plugin/` and `pluxx.config.ts` sources.
   - Confirm Codex `hooks/hooks.json` uses `${PLUGIN_ROOT}` rather than `${CODEX_PLUGIN_ROOT}` for both MDP command wrappers.
   - Do not hand-edit generated wrappers or create a second authored hook source.

3. **Strengthen manifest-bound regression proof**
   - Extend `scripts/test-pluxx-hooks.sh` so it reads and executes the exact generated Codex `SessionStart` and `UserPromptSubmit` descriptor commands from an unrelated workspace.
   - Delete `CODEX_PLUGIN_ROOT`, provide only the documented installed bundle root contract, and assert both commands exit 0.
   - Preserve no-pack-workspace no-op behavior, stdin handling, proposal routing, and Claude/Cursor/OpenCode expectations.

4. **Prepare the MDP release**
   - Advance all maintained MDP version surfaces together from 0.1.94 to the next still-unreleased patch (expected 0.1.95; re-read `main` immediately before implementation and choose a higher version if needed).
   - Update release notes/distribution truth with PLUXX-345 and MDP-211.
   - Run the complete repo validation and release/install smoke before PR handoff.

5. **Post-merge release and installed verification**
   - Release CI, not the implementation worker, owns publishing.
   - After Brandon merges, verify the immutable MDP tag/release and installed artifact.
   - Install into the active Codex cache, start a fresh Desktop thread, and prove `SessionStart` plus one submitted prompt produce no MDP hook failure.
